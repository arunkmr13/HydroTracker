# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue. Report privately through
[GitHub Security Advisories](https://github.com/arunkmr13/HydroTracker/security/advisories/new).

Include what you found, how to reproduce it, and the app version and device. You can expect an
acknowledgement within 7 days and a fix or a decision within 30 days.

## Scope

HydroTrack stores all data on the device. In scope: anything that exposes that data to other apps,
widgets, notifications or backups unexpectedly, or writes to Health Connect beyond the hydration
records the user enabled.
